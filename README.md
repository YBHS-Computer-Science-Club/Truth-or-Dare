# Truth-or-Dare

A beginner-friendly Python starter project for building a Truth or Dare generator/game.

## Starter Code

Use the starter file at:

- `/home/runner/work/Truth-or-Dare/Truth-or-Dare/truth_or_dare_starter.py`

It includes:

- A `TruthOrDareGame` class skeleton
- TODO placeholders for key variables
- Methods marked with `NotImplementedError` for you to complete
- Beginner tips and a suggested implementation order

## Beginner Requirements

Implement the TODOs so your project can:

1. Ask for and store player names.
2. Store truth and dare prompts (hard-coded lists are fine to start).
3. Randomly choose a player.
4. Let the player pick `truth` or `dare`.
5. Randomly choose and display the matching prompt.
6. Repeat rounds until players decide to stop.

## Helpful Tips

- Start small: get one round working first.
- Implement one method at a time and test after each method.
- Use clear variable names (`players`, `truth_prompts`, `dare_prompts`).
- Handle edge cases, such as empty prompt lists or no players entered.
- Keep your loop simple: setup -> round -> ask to continue.
